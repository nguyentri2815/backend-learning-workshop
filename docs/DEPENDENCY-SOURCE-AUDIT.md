## Nhánh nghiệp vụ đã lần

POST `/sale-unit/download-document/{documentType}` → SaleUnitController.downloadDocument → DownloadDocumentFunc.exec → SaleUnitRepository.findById → response 302 Location. Đọc SaleUnitRepository, lấy mã tài liệu rồi trả HTTP 302 Location dùng system.assets.url. Command không gọi InternalAssetsApi trong nhánh này; client cần Assets nếu theo redirect. Cần user/rootId và dữ liệu document hợp lệ. Context path/gateway, token và dữ liệu thử chưa xác nhận; không cấp nút gọi API thật.

## Phạm vi và bằng chứng

1333 Java files và 33 resource files đã quét; shared root có cả source test trong lượt quét chung, caller/type reference của các Feign bổ sung chỉ tìm trong Command/agent-shared src/main. Chỉ xuất đoạn được chọn, đã che literals. knownImports: 0; không có nghĩa file cấu hình bên ngoài không tồn tại. S07/S11/S17 là lịch sử setup/process, không chứng minh từng client đã gọi thành công.

Custom InvalidTokenAwareOpaqueTokenIntrospector có trong shared-auth và được Flow đăng ký; Command chỉ cấu hình opaqueToken trong ResourceServerConfiguration, nên không dùng class đó làm bằng chứng binding của Command.

Quét thêm HTTP client: HistoryUtil khai báo RestTemplate nhưng chưa tìm method call trên field đó; LoadbalancerConfig tạo bean không tự chứng minh một endpoint mới. RestDeployment/Camunda nằm ở shared-camunda, chưa thấy dependency Gradle từ các module Command/shared đã lần, nên không đưa vào danh sách service Command phải chạy.

Bằng chứng file/dòng/SHA-256 và revision nằm trong `src/content/setup/dependency-survey.json`. Không chạy Java/Docker/DB hoặc gọi API.
