2. [Kiểm tra nguyên nhân connection refused](command-merged-02-investigate.png).

Các ảnh UI trên được chọn để review giao diện. Backup, browser trace và ảnh kiểm tra cục bộ khác trong `.verification/` không thuộc gói chia sẻ. Source/cấu hình và hình ảnh trong bài vẫn cần quyền chia sẻ của chủ nguồn trước khi đưa lên một repo công khai.
