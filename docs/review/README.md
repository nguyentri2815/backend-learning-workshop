Chỉ bốn ảnh UI này được chọn và rà trực quan để bàn giao. Backup, browser trace và ảnh kiểm tra cục bộ khác trong `.verification/` không thuộc gói chia sẻ. Source/cấu hình và hình ảnh trong bài vẫn cần quyền chia sẻ của chủ nguồn trước khi đưa lên một repo công khai.
